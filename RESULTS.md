# Stage-two result

## Frozen pilot verdict: NOT SUPPORTED

The five-seed pilot passed its prerequisites but did not produce the
preregistered phantom-schema effect.

- The recurrent controller genuinely learned the held-out stable-body task:
  unavailable-action mass improved by 0.3373 from the untrained checkpoint.
- It correctly reported truthful post-removal absence.
- It did not continue acting as if the removed effector existed after negative
  sensor evidence. Zero of five seeds met the conflict criterion.
- The preregistered mean-direction state patch changed unavailable-action mass
  by only 0.000075 in the intended direction; the reverse patch changed it by
  0.00284. Both were far below the frozen 0.08 threshold.
- All evidence files reproduced byte-for-byte in a second M1 run and passed the
  recorded SHA-256 manifest.

This is a useful null result. It rejects the idea that merely giving a learned
recurrent controller a long intact history is sufficient to create the target
effect. Unlike the original stale-controller sled, this agent was not trapped
by a programmed morphology mismatch; it used the new evidence.

The next diagnostic is explicitly exploratory and cannot change this verdict.
It tests whether sensorimotor body state is linearly decodable and whether exact
matched-state replacement succeeds where the preregistered mean direction did
not. That distinction determines whether the next assay needs a better causal
intervention or a genuinely slower, consolidated world model.

## Post-null diagnostic

The sensorimotor body state was linearly decodable with 100% held-out accuracy,
but replacing the recurrent state *before* another observation produced only a
0.000068 action change. The next observation overwrote the intervention. This
is a concrete demonstration that decodability alone does not establish a
causally controlling belief.

## Causally ordered stage three: INCONCLUSIVE

Stage three was separately preregistered at commit `79583a7`. It made the agent
decide from prior state before seeing the current outcome and applied the patch
immediately before the action head.

- Stable-body competence again passed (0.3360 improvement).
- The reverse patch strongly induced limb-present action in an adapted-absent
  state (0.3282 mean effect), establishing that the learned state can causally
  drive the policy.
- The absent-state patch moved action in the predicted direction, but only by
  0.0304, below the frozen 0.08 gate and insufficiently selective from matched
  control directions.
- Truthful absence reporting lagged for approximately two decisions in most
  conditions, failing the 95% prerequisite.
- After actual negative sensor evidence, the excess unavailable-action mass
  versus a cold-absent agent was only about 0.003–0.022 across conditions—not
  the required 0.08—and never persisted for three qualifying decisions.

The stage-three run and exact replay were byte-identical and passed the evidence
manifest. The result is therefore neither a positive phantom-schema finding nor
an execution failure: it is an informative boundary result. A learned latent
body state exists and can cause action when forcibly installed, but this agent
does not exhibit the required “I know it is absent while my body model still
acts present” double dissociation.

The next justified escalation is a consolidated two-timescale world model or an
embodied language model whose body schema is learned over a long lifetime while
its declarative channel remains fast. That should be tested only with a new
preregistration and the same bidirectional interventions. Adding more physics
alone would improve realism but would not solve the missing cognitive
dissociation.
